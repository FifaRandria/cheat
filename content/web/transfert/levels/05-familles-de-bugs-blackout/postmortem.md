## Ce que ce niveau démontre

Tu viens de diagnostiquer des bugs dans quatre langages que tu n'as jamais appris. Ce n'est
pas un tour de magie : les **familles de bugs** sont les mêmes partout, et ta méthode de
diagnostic aussi.

| Famille | Où tu l'as réparée |
|---|---|
| Décalage de un | Bases de JavaScript, pagination |
| Valeur absente | `undefined`, `KeyError`, `None` |
| N+1 | SQL et bases de données, projet final |
| Attente oubliée | JavaScript asynchrone |

## Le réflexe à garder

Devant un langage inconnu : chercher d'abord les familles connues, puis la syntaxe dans la
documentation officielle. Le langage s'apprend en route.
